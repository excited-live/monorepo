## List accounts

`GET` `/api/v1/biz/accounts`

Returns every account the caller owns. A user who never saved gets the seed data.

**Responses**

- `200` — All accounts. [EntityAccount](#entityaccount)[]
- `401` — Missing or invalid bearer token (only when auth is configured). [Error](#error)

```bash

  -H "Authorization: Bearer $TOKEN"
```
