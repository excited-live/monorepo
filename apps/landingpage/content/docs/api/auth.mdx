## Current session

`GET` `/api/v1/auth/me`

Session check for native apps.

**Responses**

- `200` — Authenticated. `object`
- `401` — Missing or invalid bearer token (only when auth is configured). [Error](#error)
- `503` — Auth is not configured in this environment. [Error](#error)

```bash
curl "$API_URL/api/v1/auth/me" \
```
