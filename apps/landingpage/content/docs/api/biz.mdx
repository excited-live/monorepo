## Get the full biz snapshot

`GET` `/api/v1/biz`

Accounts, subscriptions, hardware, revenues, liabilities and transfers in one document.

**Responses**

- `200` — The snapshot. [BizSnapshot](#bizsnapshot)
- `401` — Missing or invalid bearer token (only when auth is configured). [Error](#error)

```bash
curl "$API_URL/api/v1/biz" \
  -H "Authorization: Bearer $TOKEN"
```

## Get the computed monthly ledger

`GET` `/api/v1/biz/ledger/{yearMonth}`

Cash ledger for one entity and month, derived from subscriptions, hardware, revenues and transfers.

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `yearMonth` | path | `string` | yes | `YYYY-MM`. |
| `entityId` | query | `string` | no | Defaults to the first account. |

**Responses**

- `200` — The ledger. [MonthlyLedger](#monthlyledger)
- `401` — Missing or invalid bearer token (only when auth is configured). [Error](#error)
- `404` — The user has no accounts. [Error](#error)

```bash
curl "$API_URL/api/v1/biz/ledger/:yearMonth" \
  -H "Authorization: Bearer $TOKEN"
```
