REST API behind excited.live. Every endpoint is under `/api/v1` and scoped to the authenticated user.

**Authentication.** Send `Authorization: Bearer <token>` (a Better Auth session token or API key). On environments where auth is not configured (local dev, previews) the API trusts an `x-user-id` header instead, and falls back to a shared `default` bucket.

Examples use `$API_URL` for the API base URL and `$TOKEN` for your bearer token. The machine-readable document is the committed [`apps/api/openapi.json`](https://github.com/fromsukong/excited.live/blob/main/apps/api/openapi.json).
