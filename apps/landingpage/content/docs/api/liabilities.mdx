## List liabilities

`GET` `/api/v1/biz/liabilities`

Returns every liability the caller owns. A user who never saved gets the seed data.

**Responses**

- `200` — All liabilities. [LiabilityStream](#liabilitystream)[]
- `401` — Missing or invalid bearer token (only when auth is configured). [Error](#error)

```bash
curl "$API_URL/api/v1/biz/liabilities" \
  -H "Authorization: Bearer $TOKEN"
```
