## Get onboarding state

`GET` `/api/v1/onboarding`

Returns onboarding progress for the specified app (defaults to biz-mobile).

**Parameters**

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app` | query | `string` | no | Application ID (e.g. `biz-mobile`, `webapp`). Defaults to `biz-mobile`. |

**Responses**

- `200` — The onboarding state. [UserOnboarding](#useronboarding)
- `401` — Missing or invalid bearer token (only when auth is configured). [Error](#error)

```bash
curl "$API_URL/api/v1/onboarding" \
  -H "Authorization: Bearer $TOKEN"
```

## Save onboarding state

`PUT` `/api/v1/onboarding`

Updates onboarding progress, steps completed/skipped, and overall completion status.

**Request body** (`application/json`)

Type: [UpdateUserOnboarding](#updateuseronboarding)

**Responses**

- `200` — Saved. `object`
- `400` — Malformed onboarding payload. [Error](#error)
- `401` — Missing or invalid bearer token (only when auth is configured). [Error](#error)

```bash
curl -X PUT "$API_URL/api/v1/onboarding" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ ... }'
```
