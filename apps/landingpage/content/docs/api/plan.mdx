## Get the plan

`GET` `/api/v1/plan`

The saved plan, or the default plan for a user who never saved.

**Responses**

- `200` — The plan document. [PlanInput](#planinput)
- `401` — Missing or invalid bearer token (only when auth is configured). [Error](#error)

```bash
curl "$API_URL/api/v1/plan" \
  -H "Authorization: Bearer $TOKEN"
```

## Save the plan

`PUT` `/api/v1/plan`

Stores the document as-is; a later GET returns it byte for byte.

**Request body** (`application/json`)

Type: [PlanInput](#planinput)

**Responses**

- `200` — Saved; echoes the body. `object`
- `401` — Missing or invalid bearer token (only when auth is configured). [Error](#error)

```bash
curl -X PUT "$API_URL/api/v1/plan" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ ... }'
```
