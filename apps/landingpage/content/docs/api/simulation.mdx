## Run a Monte Carlo simulation

`POST` `/api/v1/sim/monte-carlo`

Stateless; nothing is stored. `config` defaults to the engine's default configuration.

**Request body** (`application/json`)

Type: `object`

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `plan` | [PlanInput](#planinput) | yes |  |
| `config` | map of `any` | no |  |

**Responses**

- `200` — Monte Carlo result. map of `any`
- `400` — Body is not `\{ plan, config? }`. [Error](#error)
- `401` — Missing or invalid bearer token (only when auth is configured). [Error](#error)

```bash
curl -X POST "$API_URL/api/v1/sim/monte-carlo" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ ... }'
```
